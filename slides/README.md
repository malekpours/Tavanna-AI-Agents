# Course Slides

`slides/` is the canonical presentation folder for this course.

- `index.html` — course slide index
- `01-mabani.html` through `08-jam-bandi.html` — the eight modules
- `theme.css` — shared presentation styles
- `deck.js` — shared navigation and interactions
- `demos/english-course-assistant/` — English offline assistant demonstration based on repository sources

Open `index.html` in a browser. To run a single module, open its HTML file directly.
